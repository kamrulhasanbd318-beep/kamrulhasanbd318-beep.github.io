কীভাবে পরিবর্তন প্রকাশ করবেন

  1. “ওয়েবসাইট ফাইল সম্পাদনা” লিংকে চাপ দিন এবং GitHub-এ লগইন করুন।
  2. index.html-এর লেখা/ডিজাইন পরিবর্তন করুন। HTML না জানলে নিজে কোড পরিবর্তন করার আগে সাহায্য নিন।
  3. নিচে গিয়ে Commit changes চাপুন। এতে প্রকাশের প্রক্রিয়া শুরু হবে।
  4. কিছুক্ষণ পরে লাইভ সাইট খুলে refresh করুন। দরকার হলে ব্রাউজারের cache এড়িয়ে আবার খুলুন।

নিরাপদ no-code অ্যাডমিন প্যানেল সম্পূর্ণ করতে GitHub login-এর সঙ্গে একটি CMS/OAuth সংযোগ কনফিগার করতে হবে। কোনো গোপন token সরাসরি ওয়েবসাইটের HTML/JavaScript-এ রাখা নিরাপদ নয়।
